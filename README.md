# Jobs.cz AI tracker

Automatické měsíční sledování podílu AI inzerátů na jobs.cz.

- Data: `AI_jobs_tracker_jobscz.xlsx` (listy Souhrn, Porovnání, Inzeráty, Legenda)
- Snapshoty jednotlivých měření: `snapshots/`
- Metodika: `Metodika_AI_jobs_jobscz.md`
- Nastavení a řešení problémů: `SETUP_GitHub.md`

Měří se poslední den v měsíci. Zmeškaný měsíc se dožene do 10. dne následujícího měsíce.
